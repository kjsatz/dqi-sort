How well do the vectors match real sessions?

For each talk we took its nearest other talk (multi-part partners excluded) and checked whether the humans put both in the same 2026 session or session family. We also cut each representation into 43 clusters and scored those against the sessions (ARI: 0 = chance, 1 = identical). Human sessions are only one valid answer, so treat these as relative scores.
